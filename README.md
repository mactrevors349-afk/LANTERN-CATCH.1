# LANTERN-CATCH.1

A simple vibe-coded browser game inspired by a light-catching challenge.

## About

This project is a small, playful game built with HTML/CSS/JavaScript and designed to be easy to open locally in a browser.

## Description

`SIMPLE VIBE CODED GAME`

## How to run

1. Open the project folder in a code editor.
2. Launch `index.html` in your browser.
3. If needed, use a local web server for smoother behavior:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
